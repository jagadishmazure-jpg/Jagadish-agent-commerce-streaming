# Security policy

This is a learning lab with synthetic data only. Please report a vulnerability through GitHub's
**private vulnerability reporting** (Security tab, "Report a vulnerability"). Do not open a public issue.

Repository settings: secret scanning with push protection, Dependabot alerts and security updates,
CodeQL, and branch rulesets on `main` (no force-push or deletion; CI required on pull requests).

Never put real customer, payment or credential data in this repository.
